Effect of an additional FULL event (θ = 1) on the replicate concordance of Varlociraptor on {{ snakemake.wildcards.seq_platform }} data.
The left column shows the regular calls with the events ABSENT (θ = 0) and PRESENT (θ ∈ ]0,1]), the right column shows calls with the events ABSENT (θ = 0), PRESENT (θ ∈ ]0,1[) and FULL (θ = 1).
Rows show the FDR thresholds α. A site passes the threshold if the probability of either event is at least 1 - α.
Each squared bin counts the number of sites with the associated methylation rate ranges on the two replicates.
