Replicate discordance versus the number of retained CpG loci for each methylation caller and sample. Each point is one minimum coverage threshold between 0 and 30. As coverage we use the minimum mosdepth coverage of both replicates at a CpG position. Only loci that have a methylation value in both replicates and pass the threshold are retained. The x-axis shows the number of retained loci (N), the y-axis shows the discordance on these loci. The point with the highest N per curve applies no coverage filter.
