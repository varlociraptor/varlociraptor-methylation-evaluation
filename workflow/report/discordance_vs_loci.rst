Replicate discordance versus the number of retained CpG loci for each methylation caller and sample. Each Varlociraptor point is one filter level α from ``fdr_alpha``. The rightmost point (α = 1.0) applies no filter. For every level, each other caller gets the minimum coverage threshold whose number of retained loci is closest to the one of Varlociraptor. As coverage we use the minimum mosdepth coverage of both replicates at a CpG position. If a caller has fewer loci than Varlociraptor, no coverage filter is applied.
The x-axis shows the number of retained loci (N), the y-axis shows the discordance on these loci. Because the mosdepth coverages are integers and one coverage step changes the number of retained loci by more than the difference between neighbouring levels, several levels can get the same threshold. Their points then coincide, so a caller can show fewer than one point per level.
